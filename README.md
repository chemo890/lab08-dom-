## Tarea individual: Mi día

Organizador interactivo de tareas dividido en resumen, formulario y lista con búsqueda y filtros. Incluye prioridades, completar, eliminar, deshacer y guardado en este navegador.

- [Tarea: mi componente interactivo](notas/TAREA.md)
- [Ver la tarea en vivo](https://chemo890.github.io/lab08-dom-/tarea/)
- [Historial de las versiones v1, v2 y v3](https://github.com/chemo890/lab08-dom-/commits/main/)

### Archivos

- `tarea/index.html`: secciones de la página y enlace a `app.js` al final del `body`.
- `tarea/styles.css`: diseño adaptable a escritorio y móvil.
- `tarea/app.js`: clase `Tarea`, DOM, estado y eventos; dividido en seis partes comentadas.
- `notas/TAREA.md`: evolución del componente, código por versión y resultados de las pruebas.

Para actualizar una copia local del repositorio después de estos cambios, ejecuta `git pull origin main`.
